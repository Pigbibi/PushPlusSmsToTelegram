# Support

Support is provided through
[GitHub Issues](https://github.com/Pigbibi/PushPlusSmsToTelegram/issues) on a
best-effort basis.

Before opening an issue, read the README and `docs/`, run `npm test` and
`npm run lint`, check both health endpoints, and inspect a redacted Cloudflare
log. Include the commit, deployment path, expected behavior, actual behavior,
and the smallest reproducible webhook shape.

Never include credentials, real origins, chat IDs, phone numbers, SMS content,
one-time codes, KV contents, or PushPlus short links.

Follow [SECURITY.md](SECURITY.md) for vulnerabilities or data exposure. Provider
billing, account recovery, and external service outages are outside the
project's support scope.
